# Delivery Roadmap

## Milestone 0 — Discovery (current)
- Inspect existing operating-system repository and its boundaries.
- Record product decisions and MVP scope.
- Propose architecture and conceptual data model.
- Define AI operations and localization requirements.
- Record security baseline, risks, and open decisions.
- Founder reviews and approves application repository/deployment boundary.

**Exit criteria:** no critical architecture ambiguity; product scope and technical boundary approved.

## Milestone 1 — Application foundation
- Create/confirm deployable application repository.
- Inspect current Hetzner stack and choose isolated resources.
- Initialize Next.js, TypeScript, linting, formatting, tests.
- Add localization foundation (English/Arabic, RTL).
- Add authentication and user preferences.
- Add PostgreSQL and Prisma migrations.
- Add health checks and environment validation.

**Exit criteria:** deployable authenticated shell, database migrations, locale switching, automated checks.

## Milestone 2 — Core roleplay
- Scenario catalog and versioning.
- Text roleplay.
- Session persistence.
- AI provider adapter.
- Evaluation schema and rubric.
- Golden evaluation tests.

**Exit criteria:** five scenarios can be completed and evaluated with evidence-based feedback.

## Milestone 3 — Personalization
- Mistake Bank.
- Communication DNA snapshots.
- Daily practice.
- Progress view.

**Exit criteria:** repeated evidence changes the next exercise in a testable way.

## Milestone 4 — Professional writing and metering
- Email Coach.
- Usage ledger and quotas.
- AI cost dashboard/alerts.
- Voice remains deferred unless founder changes scope.

**Exit criteria:** usage is measured and bounded; email coach preserves meaning.

## Milestone 5 — Private beta and launch readiness
- Security/privacy tests.
- English/Arabic QA.
- 20–30 target users.
- Feedback usefulness and repeat-use analysis.
- Payment-provider eligibility review.
- Backup/restore and deployment rehearsal.

**Exit criteria:** founder approves private beta or records specific blockers.
